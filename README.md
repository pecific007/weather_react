# Weather React

Weather React is a simple weather WebApp that fetches the weather data of a given city (provided in the `<input>`) and display the data. This will send `https` request to https://geocoding-api.open-meteo.com to get the longitude and latitude of the city, and then send request to https://api.open-meteo.com/v1/forecast api to get the weather and display it on the card.

- Live on github pages: https://pecific007.github.io/weather_react
